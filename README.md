# Quark 2.0

> **The Future Of Programming.**

Quark is a lightweight interpreted programming language designed to be
**simple, readable, and beginner-friendly**. It lets new programmers
write programs using easy-to-understand commands without worrying about
complex syntax.

------------------------------------------------------------------------

# Features

-   Simple English-like syntax
-   Interactive Shell (REPL)
-   Variables
-   Mathematical expressions
-   User input
-   Conditional statements
-   Loops
-   Random numbers
-   File reading and writing
-   Module importing
-   Script execution
-   Built-in clock
-   Cross-platform (Windows/Linux/macOS)

------------------------------------------------------------------------

# Getting Started

Run the interpreter.

``` bash
python quark.py
```

You'll see:

    Welcome To Quark 2.0, The Future Of Programming!

    Initialising Shell...

    Done!

    >>>

You can now type Quark commands.

------------------------------------------------------------------------

# Your First Program

``` qk
print Hello World!
```

Output

    Hello World!

------------------------------------------------------------------------

# Variables

``` qk
let name = Alex
let age = 16

print 'name'
print 'age'
```

------------------------------------------------------------------------

# Mathematics

``` qk
math 5+3

let total = math 15*6

print 'total'
```

------------------------------------------------------------------------

# Random Numbers

``` qk

```

# User Input


# Command Reference

  Command              Description
  -------------------- -------------------------
  print                Prints text
  let                  Creates variables
  math                 Evaluates expressions
  random               Random numbers
  input                User input
  repeat               Repeat commands
  if                   Conditional execution
  read                 Reads a file
  write                Writes a file
  append               Appends to a file
  run                  Executes another script
  import               Imports a module
  list                 Shows variables
  clear                Clears the terminal
  time                 Shows current time
  wait                 Delays execution
  help                 Shows help
  exit / stop / kill   Closes Quark
